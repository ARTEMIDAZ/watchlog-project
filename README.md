# watchlog

Личный консольный трекер фильмов, сериалов и аниме. Данные хранятся в одном файле SQLite,
а названия, годы и число серий можно подтягивать из **TMDB** (фильмы, сериалы) и **Shikimori** (аниме).

Внешних зависимостей нет: только стандартная библиотека Python 3.8+.

## Быстрый старт

### Вариант 1. Без Docker

```
python -m watchlog --help
python -m watchlog add "Клинок, рассекающий демонов" -t anime -l
```

Чтобы команда называлась просто `watch`, установите пакет: `pip install .`

### Вариант 2. Docker

```
cp .env.example .env        # впишите TMDB_API_KEY (для аниме он не нужен)
docker compose build
./watch list                # то же, что docker compose run --rm watch list
```

База лежит в `./data/watch.db` на вашем компьютере. Скопировали папку — перенесли трекер.
На Windows вместо `./watch` используйте `docker compose run --rm watch ...`.

## Ключ TMDB

Для фильмов и сериалов нужен бесплатный ключ: <https://www.themoviedb.org/settings/api>.
Передайте его в переменной окружения `TMDB_API_KEY` (в Docker — через `.env`).
Подходит и короткий «API Key», и длинный «API Read Access Token».

Для аниме Shikimori ключ не нужен. Если TMDB недоступен напрямую, задайте прокси:
без Docker — через `HTTPS_PROXY`, в Docker — через `WATCH_PROXY` в `.env`.
Из контейнера адрес прокси на вашем компьютере обычно `host.docker.internal`, а не `127.0.0.1`.

## Команды

| Команда | Что делает |
|---|---|
| `add НАЗВАНИЕ [-t тип] [-s статус] [--total N] [-r 1-10] [-n заметка]` | Добавить запись |
| `add НАЗВАНИЕ -l [--source tmdb\|shikimori] [--pick N]` | Найти онлайн, выбрать из списка и заполнить данные |
| `search ЗАПРОС [-t тип] [--source ...]` | Поискать онлайн, ничего не сохраняя |
| `link ID [--source ...] [--pick N]` | Привязать уже добавленную запись к онлайн-базе |
| `refresh ID` / `refresh --all` | Обновить число серий (у текущих сериалов и аниме) |
| `list [-s статус] [-t тип] [-q поиск] [--sort id\|title\|rating\|finished]` | Список |
| `show ID` | Подробности и ссылка на источник |
| `progress ID --ep N` | Отметить последнюю просмотренную серию |
| `done ID [-r 1-10]` | Просмотрено |
| `rate ID N` / `drop ID` / `edit ID ...` / `rm ID [-y]` | Оценка, бросить, правка, удаление |
| `stats [-y ГОД]` | Статистика |
| `export файл.csv\|json` | Резервная копия |

Типы: `movie`, `series`, `anime`, `other`. Статусы: `planned`, `watching`, `completed`, `dropped`.

### Как работает онлайн-поиск

- `-t anime` ищет в Shikimori, `-t movie` и `-t series` — в TMDB. Без типа ищет в обоих.
- Если результатов несколько, программа покажет список и спросит номер. Для скриптов есть `--pick N` (`0` — добавить без онлайн-данных).
- Если онлайн-поиск не сработал (нет сети, нет ключа), запись всё равно добавится, с названием как вы его ввели.
- Своё название, оценку, статус и прогресс `link` и `refresh` не перезаписывают.
- `refresh --all` обновляет только записи со статусами `planned` и `watching` и делает паузы между запросами, чтобы укладываться в лимит Shikimori (5 запросов в секунду).

### Примеры

```
watch add "Во все тяжкие" -t series -l          # найдёт в TMDB, подставит 62 серии и год
watch add "Клинок, рассекающий демонов" -t anime -l --pick 1
watch progress 2 --ep 7
watch refresh --all                              # у текущего аниме подтянулось новое число серий
watch link 5                                     # привязать запись, добавленную вручную
watch stats -y 2026
```

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `WATCH_DB` | путь к файлу базы | `~/.watchlog/watch.db` (в Docker `/data/watch.db`) |
| `TMDB_API_KEY` | ключ TMDB | не задан |
| `WATCH_LANG` | язык названий TMDB | `ru-RU` |
| `SHIKIMORI_URL` | свой адрес Shikimori | пробует `shikimori.io`, затем `shikimori.one` |
| `NO_COLOR` | отключить цвета | |

База, созданная первой версией (`watch.py` одним файлом), подхватывается как есть:
недостающие столбцы добавляются сами при первом запуске.

## Устройство проекта

```
watchlog/
  cli.py          команды и разбор аргументов
  repo.py         все запросы к базе
  db.py           подключение и схема, миграция старых баз
  ui.py           таблицы и цвета
  config.py       переменные окружения
  models.py       типы, статусы
  providers/
    base.py       Meta, ProviderError, HTTP-помощник
    tmdb.py       TMDB
    shikimori.py  Shikimori
    __init__.py   выбор источника, общий поиск
tests/            тесты на поддельном сервере, интернет не нужен
```

Новый источник (например, AniList) добавляется отдельным файлом в `providers/`
с методами `search`, `details`, `url` и регистрацией в `providers/__init__.py`.
